# hey, i'm arcrek 👋

I'm an ICT student from Vietnam who turns late-night ideas into things that somehow run in production.

## things i've built

- **VeriKey** *(private, WIP)* — a multifunction ESP32-S3 security key supporting FIDO2, OpenPGP, PIV, and OATH.
- **[Telegram Order Bot](https://github.com/arcrek/TELEGRAM-ORDER-BOT)** — a self-hosted Telegram storefront with PayOS QR payments, balance payments, automatic digital delivery, and a React admin dashboard.
- **[TMail](https://github.com/arcrek/tmail)** — a passwordless temporary-mail web app and API with automatic domain provisioning through Postfix and Stalwart JMAP.
- **[Xray VLESS Go](https://github.com/arcrek/xray-vless-ws-go)** — a Go proxy server on xray-core with graceful shutdown, health checks, systemd integration, and self-updating rollback.
- **[Outlook Graph Module](https://github.com/arcrek/outlook-graph-module)** — a TypeScript/Python client for Microsoft Graph with OAuth2, retry/backoff, and 401/429 recovery baked in.
- Also shipped: a [Canva access-automation suite](https://github.com/arcrek/canva-automation), a KiotProxy manager behind Traefik, and a homelab running Proxmox, TrueNAS, AdGuard, Portainer, and Jellyfin—because paying for Netflix while self-hosting a media server is a cry for help.

## how it usually goes

1. Have a half-baked idea at 2 a.m.
2. Explain it to an AI.
3. Accept, edit, and build until it works.
4. Ship it and promise I'll document it later.

The robots haven't unionized yet. Fingers crossed.

> *“Works on my machine.”* — me, always
